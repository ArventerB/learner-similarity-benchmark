# Learner-similarity benchmark

Code, data pipeline and manuscript for the paper
**"Which Similarity Measure for Similar-Learner Retrieval? A Small-Sample Benchmark of
Fixed, Covariance-Aware and Learned Metrics on Eight Public Datasets"**.

Bản hướng dẫn tiếng Việt: [HUONG_DAN.md](HUONG_DAN.md).

## What is in this folder

| Path | Content |
|---|---|
| `manuscript/paper.md` | the manuscript (generated; do not edit by hand) |
| `manuscript/paper.docx` | the same manuscript as a Word file (generated by `tools/docx_export/export_docx.js`) |
| `manuscript/paper_template.md`, `manuscript/sections/` | the text with placeholders for every number |
| `results/figures/` | the figures (PNG at 300 dpi and PDF) |
| `results/tables/` | every table as CSV and Markdown |
| `results/summary.json` | every number quoted in the manuscript |
| `results/raw/`, `results/lomo/` | raw outputs: one row per measure, cohort and k |
| `src/lsb/download.py` | downloads the public datasets and records checksums |
| `src/lsb/extract.py` | unpacks only the needed files from the archives |
| `src/lsb/build_views.py` | builds learner ability vectors and partitions |
| `src/lsb/metrics.py` | the similarity measures and learned metrics |
| `src/lsb/protocol.py` | sampling, preprocessing, k-NN evaluation, diagnostics |
| `src/lsb/run_experiment.py` | runs the grid (resumable, parallel) |
| `src/lsb/run_extras.py` | hyper-parameter sensitivity and robustness runs |
| `src/lsb/run_skill_task.py` | fifth task: skill-specific outcomes |
| `src/lsb/check_claims.py` | asserts every hand-written statement of the paper against the data |
| `src/lsb/analysis.py`, `analysis_extras.py`, `stats.py` | tables, tests, mechanism analysis, selection rules |
| `src/lsb/figures.py` | figures |
| `src/lsb/build_paper.py` | inserts numbers and tables into the manuscript |
| `DATASHEET.md`, `docs/FEATURE_RULE.md` | data sources, licences, feature construction |
| `requirements.txt` | pinned library versions |

Raw data are not redistributed. `data/raw/MANIFEST.json` lists the URL, size and SHA-256
of every file that the download script fetches (about 1.6 GB in total).

python -m venv .venv
```

```

On Linux or macOS replace `.venv/Scripts/python` by `.venv/bin/python`.

To export the manuscript to Word (`manuscript/paper.docx`), with Node.js installed:

```bash
cd tools/docx_export && npm install && node export_docx.js
```

The Word file is regenerated from `paper.md` every time; edits made in Word are not
carried back to the Markdown source.

`extract.py` unpacks only the files that are used. XES3G5M also ships two multi-gigabyte
"window sequence" files and several thousand images; they are skipped.

`check_claims.py` exits with an error and lists the sentences to reword if a qualitative
statement of the manuscript no longer holds after a re-run. The analysis uses only the
repetitions that every cell has completed, so a partly finished block is ignored.

`run_all.sh` runs the grid in blocks of 20 repetitions. Each block takes roughly 60 to 80 minutes
on a 12-core laptop processor. Finished cells are skipped, so the script can be stopped and
restarted. A quick check of the whole pipeline:

```bash
.venv/Scripts/python -I src/lsb/run_experiment.py --views "*__d20" "oulad_*" --reps 4 --jobs 4 --out results_check/raw
```

## Design in one paragraph

Each source is turned into learner *views* (one row per learner, d ability features, one
outcome). Learners are split once into a reference pool that defines the features, a fixed
test set, and a candidate pool. A *cell* is (view, d, n). In each repetition n training
learners are drawn from the pool; scaling, covariance estimates and learned metrics are
fitted on them only; each test learner is predicted from the mean outcome of the k = 10
most similar training learners; the score is R² against the training-mean predictor.
Diagnostics of the training cohort are stored next to the scores.
